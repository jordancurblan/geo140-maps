Method

How it works

Short sets build recall faster than one long list. Clear each set without a miss, then prove it with the full mix.

01 · STUDY

Learn the layout

Every marker is labeled. Select any place for a short note on where it sits and what to remember.

02 · FIND IT

Locate on a blank map

You get a name; tap its marker. Small places sit offshore with a dotted line to their true location.

03 · NAME IT

Identify the marker

One marker is highlighted; choose its name from four options. The quiz moves on automatically.

04 · MASTER

Clear every set

Sets of five must be answered with no misses. Finish with the full mix of the whole group.
